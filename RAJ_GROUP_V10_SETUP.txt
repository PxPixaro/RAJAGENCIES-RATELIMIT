RAJ GROUP V10 — AKKI MASTER SETUP
==================================
1. Important: Make a COPY of your current Google Spreadsheet first (File > Make a copy), and download a JSON backup from the current website.
2. Open the SAME existing spreadsheet: Extensions > Apps Script.
3. Replace the previous Code.gs content with Code_V10_AKKI.gs, and Save.
4. Select function setupV10, and click Run once. Authorize Google access if requested.
5. Check that Master, Shailesh, Darshil, Dipak, User 4 and User 5 tabs still exist. The script also creates hidden _MasterSeenV10 and UserStateV8 support tabs. Do not modify those hidden tabs.
6. Deploy > Manage deployments > Edit existing deployment > Version: New version > Deploy. Using the EXISTING deployment preserves the same web app URL in the HTML.
7. Replace index.html on GitHub Pages with RAJ_GROUP_Rate_Limit_V10_AKKI.html (rename it index.html).
8. Open the website. Select each employee and enter a test bill; then select AKKI, approve a test row, and confirm that its employee tab shows YES and the status changes in the employee's browser after sync.
9. Delete the test bill from the employee seat. It should disappear from that employee's tab but remain in Master and AKKI. If you want it permanently removed from AKKI, delete the corresponding rows directly from the Google Sheets Master tab (do not clear the hidden _MasterSeenV10 tab).
10. Test the date filter (blank = all dates; choose a date to show bills created on that date).

NOTES
- User seats are isolated for active work. AKKI displays all users, including employee-deleted bills kept in historical Master.
- AKKI can approve and edit item values. Updates on active bills propagate to the employee seat. Deleted historical bills are editable only in Master/AKKI and no longer exist in employee working tabs.
- New employee items are appended to Master in the order they reach the server (roughly chronological). Existing Master rows are preserved and are not erased by employee All Clear/Delete Bill.
- If anyone manually deletes a row in Master, its Row ID is retained in hidden _MasterSeenV10 to prevent it from being restored on the next staff sync.
- Concurrent edits to the same employee seat are conflict-protected: if data is changed in another session, reload before editing. Each employee should use their own seat.
- This is a shared-link app without user authentication. Anyone with the link can choose AKKI, so do not distribute the link outside trusted staff until role-based access controls are added.
- The code has passed syntax checking but live operation against your deployed Google Apps Script and real spreadsheet cannot be verified here; complete the above test before business use.
