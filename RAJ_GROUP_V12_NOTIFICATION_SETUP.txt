RAJ GROUP V12 — Chrome/Windows Notifications

1) BACKUP current Google Sheet and Code.gs first.
2) Open Google Sheet > Extensions > Apps Script.
3) Replace Code.gs with Code_V12_Notifications.gs. Save.
4) Deploy > Manage deployments > Edit existing deployment > New version > Deploy.
   Keep the same /exec URL.
5) Upload RAJ_GROUP_Rate_Limit_V12_Notifications.html to GitHub Pages as index.html.
6) Open the website using HTTPS in Chrome. Click 'Enable Notifications' and Allow.
   Windows Settings > System > Notifications must also allow Chrome notifications.
7) Keep the browser tab open (it may be in the background). Notification checks happen approximately every 10 seconds; browser throttling can delay them.
8) Employee saves a new/changed bill: AKKI (with the website open and AKKI selected) receives a desktop notification.
9) AKKI changes approval/status/rate: the corresponding employee (with their seat selected in an open tab) receives a notification.
10) The Google Sheet stores notifications in hidden _NotificationsV12 tab, created automatically.

LIMITATIONS:
- This is polling with the browser Notification API, not true background Web Push.
- Chrome must be open on the site, Chrome/Windows notifications enabled, and the corresponding seat selected.
- Notifications will not be delivered while the browser is completely closed, or if the device sleeps. Browser background throttling may delay polling.
- Browser permission is per website origin and user profile; each device must enable it.
- Existing approval calculations, 48-hour cleanup, employee sheets, and persistent AKKI Master are unchanged.
- The notification event feed is readable via the web-app endpoint. For confidential business data consider adding authentication/access controls.
- Live end-to-end testing on your deployed Google account has not been performed.
